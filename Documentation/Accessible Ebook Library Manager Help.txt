Keyboard commands

Up and Down Arrow: Move through books. Left and Right Arrow: Move between alphabetical lists.
Type a letter: Jump to the next title beginning with that letter; leading The and A are ignored.
Enter: Open the current book. F2: Edit its metadata. Ctrl+I: Show book details. Delete: Remove books from the library (stored files are kept).
Ctrl+Space: Mark or unmark the current book for batch actions. Ctrl+A marks all books currently shown; Ctrl+Shift+A clears the marked selection.
Ctrl+F: Search metadata and indexed book text. Escape clears the search. Ctrl+L returns focus to the book list.
Ctrl+1 selects one list; Ctrl+2 selects alphabetical groups; Ctrl+3 selects one column per letter; Ctrl+4 selects tag columns. These layouts are also under Organize > Book List Display. Ctrl+N adds a book; Ctrl+Shift+N imports a folder.
Ctrl+O opens the current book. Ctrl+E exports selected books. Ctrl+K opens Kindle for PC. Ctrl+Shift+K sends books to Kindle.
Ctrl+Shift+V sends books to Voice Dream. Ctrl+Shift+E sends books to an NLS eReader. Ctrl+R converts selected books to EPUB. Ctrl+D detects metadata.
Alt+1 through Alt+0 read the corresponding configured book-list detail. Press the same shortcut twice quickly to edit that field.

Book list and selection

Each book is presented as focusable text so common screen readers can read the full title without announcing a changing item count. Open Settings > Settings, then the Book List Reading tab to choose spoken details. The visual cover preview is not included in book-list speech.
Organize > Category Layout chooses Columns or Rows for grouped views. Columns use Left and Right Arrow between categories and Up and Down Arrow between books. Rows use Up and Down Arrow between categories and Left and Right Arrow between books. Entering a category identifies it and the current book. The preference is remembered. Ctrl+1 returns to a single list, where Up and Down still move between books.
Ctrl+Space marks books for batch actions. When any books are marked, batch commands act on those books; otherwise they act on the current book.

Books and repairs

Book > Edit Metadata changes book details. Bulk Edit applies entered fields to every marked book. Find Missing Metadata Wizard (Ctrl+D) reads the book, then checks Open Library and Google Books, preserving existing values for review before saving. Look Up Metadata Online can also fill missing details. Find Cover Image Online searches for a cover without changing other metadata.
Book > Repair contains the cleanup wizard, EPUB accessibility check, page-break repair, table-of-contents rebuild, text cleanup, combining book parts, and repair-backup removal. Repair operations preserve a backup copy.
Book > Convert Selected Books to EPUB adds converted copies to the library and keeps originals. Export offers original formats or EPUB copies; export does not change books in the library. EPUB conversion requires Calibre's ebook-convert tool.
File > Send To includes Voice Dream, Dolphin EasyReader, NLS eReader, Kindle, and HumanWare MTP. Device and folder setup is in Settings.

Search and organization

Search covers book metadata and indexed text. Use Search > Re-index Book Content to build or refresh text search. Escape clears search and restores the full list.
Organize includes sorting, filters, saved views, duplicate removal, and automatic duplicate cleanup. Duplicate cleanup removes duplicate library records, not the book files.

Settings and safety

Settings > Settings opens categorized tabs. Ctrl+Tab and Ctrl+Shift+Tab switch categories; Tab moves through their controls. Choose a command to open its existing setup dialog. Categories include book-list speech, missing-metadata sound, backups, watched folders, default reader, Kindle addresses, and Calibre tools. Display layouts remain under Organize.
The Feedback tab controls optional supplementary status announcements, off by default. Help > Review Recent Messages lists the latest 10 status messages for this session, newest first. Use Up and Down Arrow to review them. Messages remain available after the status bar clears. Alt+number metadata reading remains available regardless of this setting.
Invalid metadata stays in the editor for correction. Closing an edited metadata dialog asks before discarding changes. Cancel stops supported background jobs after the current book or step; completed work is kept. Backup, restore, and individual repair steps must finish safely. Closing during active work asks before waiting, and the interface remains responsive.
Backups include the library database and imported book files. Watched folders are scanned for new or changed books and ignore known Voice Dream library notice files. Restore checks the backup before replacing library data.

Goodreads and online lookup

File > Import Goodreads Export reads the CSV file from Goodreads (My Books, Import and export, Export Library). For books already in your library it adds your shelves as tags and records your rating, reading status, date finished and review in the notes. Your own notes are kept. Goodreads books that are not in your library are added as entries tagged Wishlist, with no book file, and you are offered a text file listing them so you can look for them elsewhere. Run the import again after adding files and the entries are matched and updated rather than duplicated.
