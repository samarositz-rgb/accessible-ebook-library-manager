Keyboard commands

Up and Down Arrow: Move through books. Left and Right Arrow: Move between alphabetical lists.
Type a letter: Jump to the next title beginning with that letter; leading The and A are ignored.
Enter: Open the current book. F2: Edit its metadata. Ctrl+I: Show book details. Delete: Remove books from the library (stored files are kept).
Ctrl+Space: Mark or unmark the current book for batch actions. Ctrl+A marks all books currently shown; Ctrl+Shift+A clears the marked selection.
Ctrl+F: Search metadata and indexed book text. Escape clears the search. Ctrl+L returns focus to the book list.
Ctrl+1 selects one list; Ctrl+2 selects alphabetical groups; Ctrl+3 selects one column per letter; Ctrl+4 selects tag columns. These layouts are also under Organize > Book List Display. Ctrl+N adds a book; Ctrl+Shift+N imports a folder.
Ctrl+O opens the current book. Ctrl+E exports selected books. Ctrl+K opens Kindle for PC. Ctrl+Shift+K sends books to Kindle.
Ctrl+Shift+V sends books to Voice Dream. Ctrl+Shift+E sends books to an NLS eReader. Ctrl+R converts selected books to EPUB. Ctrl+D detects metadata.
Alt+1 through Alt+0 read the corresponding configured book-list detail. Press the same shortcut twice quickly to edit that field.

Book list and selection

Each book is presented as focusable text so common screen readers can read the full title without announcing a changing item count. Open Settings > Settings, then the Book List Reading tab to choose spoken details. The visual cover preview is not included in book-list speech.
Organize > Category Layout chooses Columns or Rows for grouped views. Columns use Left and Right Arrow between categories and Up and Down Arrow between books. Rows use Up and Down Arrow between categories and Left and Right Arrow between books. Entering a category identifies it and the current book. The preference is remembered. Ctrl+1 returns to a single list, where Up and Down still move between books.
Ctrl+Space marks books for batch actions. When any books are marked, batch commands act on those books; otherwise they act on the current book.

Books and repairs

Book > Edit Metadata changes book details. Bulk Edit applies entered fields to every marked book. Find Missing Metadata Wizard (Ctrl+D) reads the book, then checks Open Library and Google Books, preserving existing values for review before saving. Look Up Metadata Online can also fill missing details. Find Cover Image Online searches for a cover without changing other metadata.
Book > Repair contains the cleanup wizard, EPUB accessibility check, page-break repair, table-of-contents rebuild, text cleanup, combining book parts, and repair-backup removal. Repair operations preserve a backup copy.
Book > Convert Selected Books to EPUB adds converted copies to the library and keeps originals. Export offers original formats or EPUB copies; export does not change books in the library. EPUB conversion requires Calibre's ebook-convert tool.
File > Send To includes Voice Dream, Dolphin EasyReader, NLS eReader, Kindle, and HumanWare MTP. Device and folder setup is in Settings.

Search and organization

Search covers book metadata and indexed text. Use Search > Re-index Book Content to build or refresh text search. Escape clears search and restores the full list.
Organize includes sorting, filters, saved views, duplicate removal, and automatic duplicate cleanup. Duplicate cleanup removes duplicate library records, not the book files.

Settings and safety

Settings > Settings opens categorized tabs. Ctrl+Tab and Ctrl+Shift+Tab switch categories; Tab moves through their controls. Choose a command to open its existing setup dialog. Categories include book-list speech, missing-metadata sound, backups, watched folders, default reader, Kindle addresses, and Calibre tools. Display layouts remain under Organize.
The Feedback tab controls optional supplementary status announcements, off by default. Help > Review Recent Messages lists the latest 10 status messages for this session, newest first. Use Up and Down Arrow to review them. Messages remain available after the status bar clears. Alt+number metadata reading remains available regardless of this setting.
Invalid metadata stays in the editor for correction. Closing an edited metadata dialog asks before discarding changes. Cancel stops supported background jobs after the current book or step; completed work is kept. Backup, restore, and individual repair steps must finish safely. Closing during active work asks before waiting, and the interface remains responsive.
Backups include the library database and imported book files. Watched folders are scanned for new or changed books and ignore known Voice Dream library notice files. Restore checks the backup before replacing library data.

Goodreads and online lookup

File > Import Goodreads Export reads the CSV file from Goodreads (My Books, Import and export, Export Library). For books already in your library it adds your shelves as tags and records your rating, reading status, date finished and review in the notes. Your own notes are kept. Goodreads books that are not in your library are added with the tag No File Available and no book file, and you are offered a text file listing them so you can look for them elsewhere. Run the import again after adding files and the entries are matched and updated rather than duplicated. Nothing is sent to Goodreads.

File > Export Library for Goodreads saves a CSV file with titles, authors, ISBNs, shelves, ratings, reading status, dates and reviews. Goodreads does not let other programs add books directly, so on Goodreads choose My Books, Import and export, Import, and select the file. You are asked whether to include books that have no reading status; Goodreads puts those on To Read.

Online metadata lookup tries Open Library, Google Books and the Open Library ISBN record, and fills blank fields from each source.

Audiobooks

File > Import Audiobook Folder or Drive scans a folder, or a whole drive such as E:\, including every subfolder. It recognises M4B and M4A files, such as your Libation library; folders of MP3 or M4A parts, where each folder is one book (disc folders such as CD 1 and CD 2 are combined into the book above them); and ZIP files downloaded from NLS BARD or Learning Ally. Titles, authors, narrators and years come from the tags inside the files, from the book information inside a ZIP, or from folder and file names. BARD and Learning Ally books get that service as their source and their book number in the notes. A No File Available book with the same title and author is linked to its audiobook instead of being duplicated. Anything else is added with the tag Audiobook.
Before anything is added, the app shows a preview: how many audiobooks match books already in your library (such as ones imported from Goodreads), how many are new, and how many are skipped, and you can cancel. Matching ignores endings such as Book 1 and Unabridged, subtitles, series notes, and the order of authors' names, so the same book is not added twice.
Files, folders and ZIP files stay where they are. They are never copied, extracted or changed, and removing a book from the library never deletes them. Opening a folder book starts its first part in your default player. Opening a ZIP hands it to whatever your computer uses for ZIP files, so you may need to extract it or open it in a DAISY player. If the drive is not connected, the book is reported as missing until it is back. Run the import again after adding more books; ones already in the library are skipped.

Converting audiobooks to M4B

Book > Convert Selected Audiobooks to M4B turns the selected audiobooks into single M4B files. It works on folders of MP3 or M4A parts, single MP3 or M4A files, and audio ZIP files from NLS BARD or Learning Ally. Each part becomes a chapter, and the title, author, narrator and year are written into the new file. A single M4A is copied across without re-encoding. You choose the output folder, which is remembered, and the original files are never changed or deleted. Each converted book then opens its new M4B, and its notes record where it came from. You can cancel while it runs; books already finished are kept.
This needs FFmpeg, a free tool that is not included with this app. If it is not found, the app tells you how to install it: open PowerShell and type winget install Gyan.FFmpeg, then restart the app. You can also point the app at an ffmpeg.exe you already have. Protected audiobooks that FFmpeg cannot read are reported and skipped.

Books you have and books you do not

A book with no file in your library is read out with the words No file available at the end. Organize > Filter has three choices: Show Only Books I Have, Show Only Books I Do Not Have (No File Available entries and books whose file has gone missing), and Show Books Whether or Not I Have Them. The filter is also stored in saved views, and Clear Filters resets it.

Finding a book elsewhere

Book > Find Book on Other Services lists places to look for the selected book in one list. Project Gutenberg is searched for you and any free matches come first. After that come the free and accessible services (Bookshare, NLS BARD, Learning Ally, Internet Archive, Standard Ebooks, Open Library, HathiTrust and Project Gutenberg), the commercial services (Audible, Libro.fm, the Kindle Store on Amazon, Apple Books, Kobo, Google Play Books, Barnes and Noble and Bookshop.org), and your local library (Libby and OverDrive, and Hoopla). Press Enter on a line to open only that one in your browser.
NLS BARD and Learning Ally have no public search address, so the app opens their site and copies the search words for you to paste after you sign in. The first time you open Libby, the app asks for your library's name, such as nypl for nypl.overdrive.com, and remembers it so later searches go straight to your library. The app never handles your logins, buys nothing and downloads nothing.
